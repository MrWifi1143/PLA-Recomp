Pokémon Legends: Arceus recompiled for Windows and Linux. This repository only holds the releases, which is where
[RecompLauncher](https://recomplauncher.com) installs and updates the game from.

- **Source code, issues and every older release:** [MrWifi1143/LZA-Recomp](https://github.com/MrWifi1143/LZA-Recomp/tree/LegendsA)
  (branch `LegendsA`), also on [GitLab](https://gitlab.com/mr.wifi1143/LZA-Recomp).
- **Help and news:** [Discord](https://discord.gg/wxqppgye97).

## Install

- **With RecompLauncher:** find PL:A Recomp in Discover. It asks for your game files and `prod.keys` and sets the game up.
- **Windows by hand:** download `LZA-Recomp-PLA-windows-x64-v<version>.zip` from the
  [latest release](https://github.com/MrWifi1143/PLA-Recomp/releases/latest), unzip it anywhere and start `PLARecomp.exe`.
- **Linux:** download `LZA-Recomp-PLA-linux-x86_64-v<version>.AppImage`, make it executable and open it. Settings, saves
  and game files go to `~/.local/share/plarecomp`.

You need your own copy of Pokémon Legends: Arceus (the base game's `.nsp` / `.xci` and the 1.1.1 update) and the `prod.keys` dumped
from your own Switch. Nothing from the game is in these releases.
